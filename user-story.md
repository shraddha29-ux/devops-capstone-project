# User Story Template

## Format
> **As a** <role/user type>,  
> **I want** <an action or feature>,  
> **So that** <business value or benefit>.

## Acceptance Criteria
- [ ] Criterion 1: Service responds successfully with expected status codes.
- [ ] Criterion 2: All unit tests pass cleanly under `nosetests`.
- [ ] Criterion 3: Lint checks pass via Flake8 and Pylint.
